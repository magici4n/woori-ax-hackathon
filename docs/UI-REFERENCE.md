# UI / UX 흐름

2026-10-27 사용자 요청에 따라 자산 → 시뮬레이션/근거 → 대화 → 재시뮬레이션으로 개편했습니다.

- 첫 화면은 합산 자산 요약과 보유 종목 표입니다. 상단과 표 아래에 절세 시뮬레이션 시작 버튼을 둡니다.
- 결과는 세 가지 시나리오의 감소액·세금·비용·매도 내역·선택 이유를 나란히 보여줍니다. 선택한 카드에 맞춰 종목별 이유를 표시합니다.
- 기업의 성장과 위험 요약은 결과 아래에 펼쳐서 표시하고 발행일과 실제 원문 링크를 붙입니다. 자동 AI 해설이 실패해도 이 근거는 유지합니다.
- 결과 뒤의 큰 대화 진입 버튼으로 투자 의사를 전달합니다. 답장에 재계산 버튼을 표시하되, 사용자가 계속 대화할 수 있도록 입력창을 유지합니다.
- 대화 초안과 마지막 계산 조건을 분리합니다. 재계산 버튼을 누른 뒤 성공해야 적용하고, 이전 최대 감소액과 달라진 값을 표시합니다.

우리투자증권 참고 색상·브랜드 헤더·정보 카드 스타일을 유지했습니다. App.jsx는 상태와 API, PortfolioResults.jsx는 자산 및 결과 화면, simulation-flow.css는 새 배치를 관리합니다. 루트 Gradle 통합 없이 frontend와 backend를 각각 실행합니다.

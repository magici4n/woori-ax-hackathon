# 첨부 프론트 화면 반영 결과

참고 자료: 사용자가 최종으로 제공한 9쪽 화면 PDF (`최최종UI.pdf`). 디자인과 사용자 흐름을 참고했으며, PDF 안의 예시 수치와 종목은 실제 앱 데이터로 간주하지 않았습니다.

## 이번에 반영한 화면

| 참고 화면 | 현재 구현 |
|---|---|
| 1. 보유 자산과 시작 버튼 | 시연 계좌의 실제 API 응답으로 평가액·예상 세금·종목별 수량과 손익 표시 |
| 2~4. 내 계좌 분석 | 왼쪽 세로 단계 표시와 넓은 분석 화면. `/api/simulation`의 Java 계산과 `/api/research/live`의 웹 검색·AI 요약을 동시에 시작. 작업 중에는 원형 표시가 회전하고 완료 항목을 표시. PDF의 임의 70% 수치는 사용하지 않음 |
| 5. 이벤트 분석 | 보유 종목별 자료 종류·확인된 일정, AI 분석 요약·주요 이벤트·뉴스/리포트·실적 분석·매도 검토 포인트·원문 탭과 대화 진입 |
| 6. AI 상담 패널 | 오른쪽 상담 패널, 기존 챗봇 API, 빠른 질문, 대화 기록, 보유 요약, 조건 미리보기, 직접 조건 수정 연결 |
| 7~8. 시나리오 선택 | 매도 수량·예상 세금·수수료·실현손익·AI 검색 출처가 포함된 세 카드 비교와 선택 |
| 9. 선택한 시나리오 보고서 | 세금 전후 비교·종목별 가상 매도 수량·핵심 요약·주의사항·출처·브라우저 PDF 인쇄 |

## 추가 작업이 있어야 하는 기능

| PDF의 표현 또는 기능 | 현재 빠진 이유 | 필요한 작업 |
|---|---|---|
| 실시간 계좌·현재가·매매 이력 | 현재 `/api/portfolio`는 시연 자산 | 증권사 인증·계좌/시세/거래 연동, 개인정보 보호 및 오류 처리 |
| 예정 실적발표·배당일 달력 | 웹 조사에서 출처에 연결된 일부 일정만 표시하며 완전한 달력 데이터가 없음 | 일정 데이터 공급원과 조회 API, 공식/추정 여부·시각·시간대·출처 관리 |
| 애널리스트 매수 비율·목표가·실시간 PER | 현재 근거 데이터에 없음 | 별도 라이선스/데이터 API, 발표일·기준일·계산 기준 표시 |
| 투자 목적을 별도 구조화 조건으로 적용 | 현재는 필요 현금과 보유 계획 개월 수를 지원하지만 자유로운 투자 목적 분류는 없음 | 목적별 입력 정의와 검증, 결과 표시 추가 |
| 특정 날짜의 매도 시기·연말 일정 제안 | 거래일, 결제일, 실적 일정과 과세 귀속 검증이 없음 | 시장 캘린더·증권사 결제 규칙·세무 검증을 포함한 일정 엔진 |
| 매도 주문 실행 및 주문 후 리포트 | 주문 API가 없고 시뮬레이션만 수행 | 인증된 거래 연동과 주문 전 확인·취소·체결 처리. 별도 검토 필요 |
| 서버에서 다운로드되는 정식 PDF 파일 | 현재는 브라우저 인쇄 메뉴의 PDF 저장 | 파일 생성 API 또는 클라이언트 PDF 렌더러, 출력 서식·이력 관리 |

첫 화면에서 **내 양도소득세 줄이기**를 누르면 `/api/simulation`과 `/api/research/live`를 동시에 호출합니다. 후자는 실제 웹 검색을 수행하고, 별도 AI 호출로 인용 출처를 종목별 기사 카드와 요약·성장 요인·위험·분석 코멘트로 정리합니다. 두 작업이 완료되면 기업 자료 확인 버튼이 활성화되어 다음 화면에서 결과를 즉시 볼 수 있습니다. 실패한 작업만 다시 시도할 수 있으며 검색 실패 시 자료 없이 진행할 수도 있습니다. 정적 JSON 요약은 기업 자료 화면에서 제거했습니다. 검색 자료는 서버에서 30분간 재사용해 챗봇과 시나리오에 전달합니다. 요약에 실패하면 원문 링크만 표시합니다. 시나리오에는 종목별 매도·보유 이유와 필요 현금 충족 여부를 표시합니다. API 실패 시 Java 기본 계산을 표시하고, 이때 보유 계획은 전략에 반영되지 않았다고 명시합니다. 일정 달력과 배당일은 아직 없으며, 확인하지 못한 미래 일정을 채워 넣지 않습니다. PDF의 Microsoft·Alphabet 종목과 예시 금액은 현재 시연 자산의 Tesla·Apple·NVIDIA·Amazon 및 실제 계산값으로 대체했습니다.

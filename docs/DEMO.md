# 시연 순서

IntelliJ에서 backend의 TaxApplication, VS Code 또는 IDE에서 frontend의 dev를 각각 실행합니다. 화면 주소는 http://127.0.0.1:5173 입니다.

1. **내 자산 확인:** 첫 화면에서 6개 종목의 수량·평가액·손익과 올해 예상 세금을 확인합니다. ‘내 양도소득세 줄이기’를 누릅니다.
2. **계산과 기업 자료 조사:** ‘내 계좌 분석’ 화면에서 Java 세금 계산과 OpenAI 웹 검색·기사 요약이 동시에 시작됩니다. 진행 중에는 원형 표시가 회전하고, 각 작업이 끝날 때마다 진행 항목이 완료로 바뀝니다. 모두 끝나면 ‘기업 자료 확인하기’를 누릅니다.
3. **기업 자료 확인:** 이미 수집한 기사·공시를 종목별로 확인합니다. 각 카드에 원문 링크, 자료 요약, 성장 참고 요인, 위험, AI 분석 코멘트가 표시됩니다. 요약을 검증하지 못한 경우에는 원문 링크만 표시합니다.
4. **투자 의사 대화:** ‘AI와 절세 계획 세우기’를 누른 뒤 ‘테슬라는 장기투자 중이라 팔 생각 없어’라고 말합니다. 챗봇이 매도 제외 조건을 정리합니다. 모호하게 말하면 확인 질문에 답합니다.
5. **시나리오 비교:** ‘시나리오 보기’를 누릅니다. OpenAI가 조사 자료와 사용자 조건을 바탕으로 두 매도 전략을 제안하고, Java가 수량과 세액을 검증·계산합니다. 제안에 실패하면 Java 기본 계산을 보여줍니다.
6. **다시 조정:** 대화로 돌아가 ‘애플도 절반까지만 팔래’라고 말하고 다시 계산합니다. 기존 테슬라 제외 조건은 유지됩니다.

계좌·가격·환율은 시연용 가상 값입니다. 검색 자료의 사실과 날짜는 연결된 원문에서 확인해야 합니다. 실제 OpenAI 호출은 유료 크레딧을 소모하므로 자동화 테스트에서는 모의 응답만 사용합니다.

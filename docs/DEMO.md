# 시연 순서

IntelliJ에서 backend의 TaxApplication, VS Code 또는 IDE에서 frontend의 dev를 각각 실행합니다. 화면 주소는 http://127.0.0.1:5173 입니다.

1. **내 자산 확인:** 첫 화면에서 4개 종목의 수량·취득가·평가액·손익과 올해 예상 세금 550,000원을 확인합니다. ‘AI와 대화하기’를 누릅니다.
2. **투자 의사 대화:** ‘테슬라는 장기투자 중이라 팔 생각 없어’라고 말합니다. 챗봇이 테슬라 매도 제외를 조건으로 정리합니다. 모호하게 말하면 확인 질문에 답한 뒤 진행합니다.
3. **조건 확인:** 오른쪽에서 매도 제한과 AI 균형안 기준을 확인합니다. 기본 조건으로도 계산할 수 있으며, 직접 조건 수정도 가능합니다. ‘내 시나리오 보기’를 누릅니다.
4. **시나리오 비교:** Java 계산 기준을 먼저 보여줍니다. 사용자 제한을 반영한 최대 절세액과 종목별 매도 수량을 확인합니다.
5. **최신 자료 조사와 AI 제안:** OpenAI가 뉴스·공시·실적발표 일정을 웹 검색하고 출처가 연결된 근거로 서로 다른 두 매도 전략을 제안합니다. Java는 제안 수량이 보유량과 사용자 제한을 지키는지 확인하고 세금·수수료·남은 자산을 계산합니다. 검색이나 AI 제안이 실패하면 기존 Java 계산 결과를 유지합니다.
6. **다시 조정:** 대화로 돌아가 ‘애플도 절반까지만 팔래’라고 말하고 다시 계산합니다. 테슬라 제외 조건은 유지되고 애플 매도 한도가 추가됩니다. 화면에서 보유 우선 또는 절세 우선 기준을 바꿔 AI의 전략 제안을 다시 비교할 수도 있습니다.

계좌·가격·환율은 시연용 가상 값입니다. 검색 자료의 사실과 날짜는 연결된 원문에서 확인해야 합니다. 실제 OpenAI 호출은 유료 크레딧을 소모하므로 자동화 테스트에서는 모의 응답만 사용합니다.

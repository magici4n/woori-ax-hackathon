# 시연 순서

IntelliJ에서 backend의 TaxApplication, VS Code 또는 IDE에서 frontend의 dev를 각각 실행합니다. 화면 주소는 http://127.0.0.1:5173 입니다.

1. 첫 화면에서 4개 보유 종목의 수량·취득가액·평가액·손익과 올해 예상 세금 550,000원을 봅니다.
2. ‘절세 시뮬레이션 시작’을 누릅니다. 보유 유지(감소 0원), 일부 절세(테슬라 15주, 감소 285,872원), 절세 우선(테슬라 29주, 감소 550,000원)을 비교합니다.
3. 각 카드의 계산상 선택 이유, 종목별 매도·보유 내역, 기업 자료의 성장·위험과 원문 링크를 확인합니다. AI 추가 해설은 계산 후 자동 요청되며 실패해도 원문 자료와 계산은 남습니다.
4. ‘내 투자 의사 이야기하기’를 누르고 ‘테슬라는 장기투자 중이라 팔 생각 없어’라고 말합니다. 매도 제외 초안이 생겨도 기존 결과는 바뀌지 않습니다.
5. 더 이야기하거나 답장의 ‘이 조건으로 다시 시뮬레이션’을 누릅니다. 테슬라는 50주 보유하고 애플을 대안으로 계산합니다. 최대 세금 감소는 190,795원, 예상 세금은 359,205원입니다. 이전 최대 감소액과 차이도 표시합니다.
6. 대화로 돌아가 ‘애플도 절반까지만 팔래’라고 추가합니다. 테슬라 제외는 유지하고 애플의 최대 매도 수량을 12주로 제한합니다. 다시 계산하면 감소액은 91,582원입니다.
7. ‘조금 손해보더라도 공격적으로 투자하고 싶어’에는 보유 비중 유지와 매도 후 재투자 중 어느 뜻인지 물어 구체화해야 합니다. 임의의 주가 전망이나 새 매수 종목으로 바꾸지 않습니다. 보유 비중을 유지하려면 종목별 수량/비율로 정합니다.
8. 직접 조건 수정에서 제외 해제·매도 한도 완화를 명시적으로 수행할 수 있습니다. 새 대화는 적용된 조건을 유지하고 대화 초안만 취소합니다.

자료는 2026-10-27에 원문을 확인한 저장 자료입니다. 실시간 뉴스 피드가 아니며, 계좌·가격·환율은 시연용 가상 값입니다. 전체 잔여 주식의 ±10% 가정은 예측이 아닙니다.

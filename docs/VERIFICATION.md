추가 검증: 장기 보유 의사의 확인 질문 → 짧은 긍정 답변 → 적용 예정 조건 → 사용자 확정 → 결과 이동을 브라우저에서 확인했습니다. 확정 전에는 결과가 열리지 않으며, 테슬라 제외 확정 후 허용 수량 0주·전량 매도 불가·보유 유지 세금 550,000원이 표시됐습니다. 종목 변경, 대화 초기화, 만료된 대화의 짧은 응답은 이전 질문을 재사용하지 않습니다. 대화 이력 12개, 세션 100개, 유효기간 30분 제한을 테스트했습니다.

자동 검증 18개 통과: `ScenarioServiceTest` 10개, `AssistantServiceTest` 6개, `ApiTest` 2개. 프론트엔드 Vite production build 통과.

빌드 구조는 backend의 독립 Gradle Wrapper 8.14.3과 frontend의 npm/Vite로 분리했습니다. 테스트 보고서는 `backend/build/reports/tests/test/index.html`, API 전용 실행 파일은 `backend/build/libs/tax-scenario-0.1.0.jar`입니다. Wrapper JAR과 배포판은 공식 SHA256으로 검증했습니다.

분리 후 재검증: backend에서 `clean build`로 테스트 18개가 통과했고 frontend의 `npm run build`도 통과했습니다. React 개발 서버의 5173 화면 HTTP 200, 기존 8080 직접 API와 5173 프록시 API의 동일 응답을 확인했습니다. 8080 서버를 그대로 두기 위해 새 API 전용 JAR은 18080 포트에서 별도로 실행해 자산 API 정상 응답과 루트 HTTP 404를 확인한 뒤 종료했습니다. JAR에 React 정적 파일이 포함되지 않는 것도 확인했습니다.
